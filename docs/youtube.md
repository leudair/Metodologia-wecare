## Configurações no YouTube Studio

| Etapa | Campo | O que escolher |
|---|---|---|
| Detalhes | Miniatura | Enviar arquivo → `miniatura-youtube-metodologia-wecare.jpg` |
| Detalhes | Playlists | Nenhuma |
| Detalhes | Público | **Não é conteúdo para crianças** (se marcar "para crianças", a incorporação no site fica limitada) |
| Detalhes → Mostrar mais | Permitir incorporação | **Marcado** (sem isso o vídeo não toca no site) |
| Detalhes → Mostrar mais | Idioma do vídeo | Português (Brasil) |
| Detalhes → Mostrar mais | Categoria | Educação |
| Detalhes → Mostrar mais | Comentários | Pode desativar, já que o vídeo é não listado |
| Elementos do vídeo | Tela final e cards | Não adicionar (levariam a pessoa para fora da página) |
| Visibilidade | Visibilidade | **Não listado** |

Com o vídeo publicado, envie o link (`https://youtu.be/...`) para configurar a página.
